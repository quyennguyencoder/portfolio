# 🎨 Personal Portfolio

My personal portfolio website showcasing my skills, projects, and experience as a Java Backend Engineer.

## ✨ Features

- 🌓 Dark/Light mode toggle
- 📱 Fully responsive design
- 🎬 Smooth animations with Framer Motion
- ⚡ Fast performance with Vite
- 🎯 Modern UI with Tailwind CSS v4

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Build Tool:** Vite
- **Icons:** React Icons

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/quyennguyencoder/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
